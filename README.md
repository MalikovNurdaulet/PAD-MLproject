### 📝 Вывод

Для исследования использован реальный набор данных Student Performance из UCI Machine Learning Repository, содержащий 649 наблюдений и 33 столбца.

Работа выполнена в четыре этапа:

ЛР6 — Разведочный анализ данных (EDA). Изучены структура датасета, распределения признаков, взаимосвязи между учебными и социально-образовательными характеристиками и итоговой оценкой G3.

ЛР7 — Подготовка данных. Проведены проверка качества данных, обработка признаков и подготовка воспроизводимого процесса предобработки с использованием Pipeline.

ЛР8 — Регрессия. Обучены и сравнены LinearRegression, Ridge и Lasso. Наилучший результат показала Lasso с CV R² = 0.8378 и CV RMSE = 1.2995. Проведены эксперименты с преобразованием признаков, регуляризацией и интерпретацией коэффициентов.

ЛР9 — Классификация. Разработана модель LogisticRegression для определения учащихся с риском неуспеваемости (G3 < 10). Подбор порога классификации позволил увеличить CV F1 с 0.7220 до 0.7712, а Test Recall — с 0.72 до 0.88. Это повысило способность модели выявлять учащихся, которым может потребоваться дополнительная академическая поддержка.

✅ Итог

В результате создан структурированный ML-проект, объединяющий анализ данных, подготовку признаков, регрессию, классификацию и оценку качества моделей.

Полученные результаты демонстрируют возможность применения машинного обучения для анализа успеваемости и раннего выявления академических рисков. При этом модель классификации с признаками G1 и G2 предназначена для оценки риска после получения промежуточных оценок.

Проект может служить основой для дальнейшей разработки информационно-аналитической системы мониторинга результатов учащихся. (СОр/СОч, четвертные оценки, год, ЕНТ, МЭСК)
