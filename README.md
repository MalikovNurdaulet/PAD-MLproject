## 📌 Описание проекта

Цель проекта — разработать воспроизводимую систему машинного обучения для прогнозирования академической успеваемости учащихся и выявления риска неуспеваемости на основе учебных и социально-образовательных характеристик.

## 🛠️ Технологии
`Python` · `NumPy` · `pandas` · `scikit-learn` · `Jupyter` · `Matplotlib` · `Git / GitHub`

## 📊 Датасет

- Количество наблюдений: 649
- Количество признаков: 33 столбца, включая целевую переменную
- Пропущенные значения: 0
- Целевая переменная регрессии: `G3` — итоговая оценка (0–20)
- Целевая переменная классификации: `at_risk` — риск неуспеваемости (`G3 < 10`)

**Источник:** https://archive.ics.uci.edu/dataset/320/student+performance
