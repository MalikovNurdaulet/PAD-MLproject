**Цель:** подготовить датасет Student Performance для дальнейшего построения моделей машинного обучения, проверить корректность данных и разработать воспроизводимый процесс предобработки.

## 2.8. Создание новых признаков (Feature Engineering)

Для повышения интерпретируемости данных предложены дополнительные признаки, основанные на исходных характеристиках учащихся.

Исследовательские расчёты выполнены по исходному CSV. Их реализацию необходимо дополнительно внести в проект.

### 2.8.1. Группы по количеству пропусков

Создана экспериментальная группировка `absence_group`.

| Категория | Количество пропусков |
|---|---|
| 0 | Нет пропусков |
| 1–5 | От 1 до 5 |
| 6–15 | От 6 до 15 |
| 16+ | Более 15 |

### 📊 Результат

| Группа | Учащиеся | Средняя G3 | Медиана | Группа риска, % |
|---|---:|---:|---:|---:|
| 0 | 244 | 12.04 | 13 | 13.93 |
| 1–5 | 234 | 12.06 | 12 | 13.68 |
| 6–15 | 150 | 11.61 | 11 | 19.33 |
| 16+ | 21 | 10.76 | 10 | 23.81 |

**Вывод:** у учащихся с большим количеством пропусков наблюдаются более низкие средние итоговые оценки и более высокая доля неуспеваемости.

Данная группировка позволяет исследовать потенциально нелинейную зависимость между посещаемостью и академическими результатами.

### 2.8.2. Наличие предыдущих академических неудач

Предложен бинарный признак `has_failures`:

- `yes` — у учащегося была хотя бы одна предыдущая академическая неудача;
- `no` — предыдущие неудачи отсутствуют.

### 📊 Результат

| Категория | Учащиеся | Средняя G3 | Группа риска, % |
|---|---:|---:|---:|
| no | 549 | 12.51 | 9.29 |
| yes | 100 | 8.59 | 49.00 |

**Вывод:** наличие предыдущих академических неудач связано со значительно более низкой итоговой успеваемостью.

Признак может использоваться как дополнительный индикатор академического риска.

### 2.8.3. Средний уровень образования родителей

Предложен числовой признак `parent_edu_mean`, рассчитываемый как среднее арифметическое `Medu` и `Fedu`.

Он обобщает два исходных порядковых показателя и может использоваться при анализе семейных характеристик.

При этом новый показатель не заменяет автоматически исходные признаки: его полезность необходимо проверить на кросс-валидации.

### 2.8.4. Целевая переменная классификации

Для будущей ЛР9 предусмотрена бинарная переменная `at_risk`:

- `1`, если `G3 < 10`;
- `0`, если `G3 >= 10`.

| Категория | Количество | Доля |
|---|---:|---:|
| Группа риска | 100 | 15.41% |
| Остальные учащиеся | 549 | 84.59% |

**Важно:** `at_risk` вычисляется непосредственно из G3 и не должна использоваться как входной признак при прогнозировании G3.

Для классификации, наоборот, из входных признаков необходимо исключить G3.

### 📝 Общий вывод

Дополнительные признаки позволяют представить академические характеристики в более интерпретируемом виде.

Однако увеличение количества признаков не обязательно приводит к улучшению модели. Необходима экспериментальная проверка качества на кросс-валидации.

## 2.10. Предобработка в Pipeline и оценка модели

Для проверки пригодности набора данных к машинному обучению проведён отдельный контрольный эксперимент с линейной регрессией.

**Целевая переменная:** `G3`.

Использованы 15 числовых и 17 категориальных входных признаков.

**Предобработка:**

- SimpleImputer со стратегией median для числовых признаков.
- StandardScaler для стандартизации.
- SimpleImputer со стратегией most_frequent для категориальных признаков.
- OneHotEncoder с обработкой неизвестных категорий.
- LinearRegression в качестве базовой модели.

**Параметры эксперимента:**

| Параметр | Значение |
|---|---|
| test_size | 0.25 |
| random_state | 42 |
| Обучающая выборка | 486 |
| Тестовая выборка | 163 |
| Кросс-валидация | 5 фолдов |
| Основная метрика | R² |

### 📊 Контрольные результаты

| Метрика | Значение |
|---|---:|
| CV R², фолд 1 | 0.7825 |
| CV R², фолд 2 | 0.7728 |
| CV R², фолд 3 | 0.8233 |
| CV R², фолд 4 | 0.8665 |
| CV R², фолд 5 | 0.8631 |
| **Средний CV R²** | **0.8216** |
| Средний CV RMSE | 1.3625 |
| Test R² | 0.8653 |
| Test RMSE | 1.1655 |

### 📝 Вывод

Базовая линейная модель демонстрирует достаточно высокое качество прогнозирования итоговой оценки.

Средний коэффициент детерминации на кросс-валидации составляет около 0.82.

RMSE измеряется в баллах итоговой оценки.

Применение Pipeline позволяет выполнять заполнение пропусков, стандартизацию и кодирование категорий непосредственно внутри каждого обучающего фолда, предотвращая утечку информации при кросс-валидации.

### Сравнение SimpleImputer и KNNImputer

Проведён контрольный сравнительный расчёт для двух методов заполнения пропусков.

| Метод | Средний CV R² | Средний CV RMSE |
|---|---:|---:|
| SimpleImputer (median) | 0.8216 | 1.3625 |
| KNNImputer (5 соседей) | 0.8216 | 1.3625 |

**Вывод:** результаты совпадают, поскольку исходные числовые признаки не содержат пропущенных значений.

Следовательно, ни SimpleImputer, ни KNNImputer не изменяют их значения.

При отсутствии пропусков использование более сложного метода не даёт преимуществ.

## 2.11. Итоговые выводы

По результатам подготовки и контрольных экспериментов установлено:

1. **Качество исходных данных.** Датасет содержит 649 наблюдений и 33 столбца. Явные пропуски и полные дубликаты отсутствуют.

2. **Типы и категории.** Числовые и текстовые столбцы имеют согласованную структуру. Дополнительное исправление категориальных значений не потребовалось.

3. **Проверка допустимых значений.** Некорректные значения проверенных показателей не обнаружены.

4. **Потенциальные выбросы.** Метод IQR выявил необычные значения возраста, посещаемости и оценок. Они сохранены, поскольку могут иметь содержательное значение.

7. **Предобработка.** Для предотвращения утечки данных используется Pipeline с заполнением пропусков, стандартизацией и кодированием категорий.

8. **Базовая модель.** В контрольном эксперименте средний CV R² линейной регрессии составил 0.8216.

9. **Методы заполнения пропусков.** SimpleImputer и KNNImputer показали одинаковые результаты, поскольку в исходных данных отсутствуют пропущенные значения.
