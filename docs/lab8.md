
# 📈 Этап 3. Линейная регрессия, регуляризация и интерпретация модели (ЛР8)

**Цель:** разработать воспроизводимую модель прогнозирования итоговой академической оценки учащихся с использованием линейной регрессии и методов регуляризации.

**Задачи:**
1. Подготовить обучающую и тестовую выборки.
2. Построить базовую модель LinearRegression.
3. Найти коэффициенты парной регрессии аналитически.
4. Рассчитать MSE, RMSE и R².
5. Исследовать нелинейные преобразования признаков.
6. Сравнить LinearRegression, Ridge и Lasso.
7. Оценить важность признаков.
8. Реализовать обучение в `src/train.py`.
9. Зафиксировать параметры и метрики экспериментов в Git.

## 3.3. П1. Базовая модель LinearRegression

Для прогнозирования итоговой оценки учащихся `G3` построена базовая модель `LinearRegression`.

Предобработка данных и обучение объединены в `Pipeline`:

- Числовые признаки: `SimpleImputer(strategy="median")` и `StandardScaler`.
- Категориальные признаки: `SimpleImputer(strategy="most_frequent")` и `OneHotEncoder(handle_unknown="ignore")`.
- Модель: `LinearRegression`.
- Оценка качества: 5-кратная кросс-валидация.

### 📝 Вывод

Базовая модель LinearRegression показала средний R² = 0.8216 на кросс-валидации и R² = 0.8653 на тестовой выборке.

Значение Test RMSE = 1.1655 означает, что среднеквадратическая ошибка прогноза составляет около 1.17 балла по шкале оценок от 0 до 20.

Разница между CV R² и Test R² не указывает на выраженное переобучение, однако устойчивость модели необходимо дополнительно проверить.

Полученные метрики принимаются за базовый уровень для дальнейшего сравнения моделей Ridge и Lasso.

## 3.4. П2. Формула метода наименьших квадратов (МНК)

Для парной линейной регрессии выбран признак `G2` — оценка учащегося за второй учебный период. Целевая переменная — итоговая оценка `G3`.

Коэффициенты регрессии рассчитаны четырьмя способами:

1. `np.linalg.inv()` — через обратную матрицу.
2. `np.linalg.solve()` — решение системы линейных уравнений.
3. `np.linalg.lstsq()` — метод наименьших квадратов.
4. `LinearRegression()` — реализация scikit-learn.

### 📊 Результаты расчёта коэффициентов

| Метод | w₀ | w₁ |
|---|---:|---:|
| np.linalg.inv | -0.0559 | 1.0343 |
| np.linalg.solve | -0.0559 | 1.0343 |
| np.linalg.lstsq | -0.0559 | 1.0343 |
| LinearRegression | -0.0559 | 1.0343 |

Полученное уравнение регрессии:

**G3 = -0.0559 + 1.0343 × G2**

При увеличении оценки G2 на один балл прогнозируемая итоговая оценка G3 увеличивается примерно на 1.03 балла.

### Проверка вырожденности матрицы

Для проверки добавлена копия признака G2.

### 📊 Результаты с дублирующим признаком

| Метод | Результат |
|---|---|
| np.linalg.inv | Singular matrix |
| np.linalg.solve | Singular matrix |
| np.linalg.lstsq | Успешное решение |
| LinearRegression | Успешное решение |

После дублирования признака матрица содержит три столбца, но её ранг равен двум.

Методы `inv` и `solve` не работают, поскольку матрица XᵀX вырождена и не имеет обратной матрицы.

Методы `lstsq` и `LinearRegression` находят решение, распределяя коэффициент исходного признака между двумя одинаковыми столбцами:

**w₁ = 0.5172, w₂ = 0.5172**

Суммарный коэффициент остаётся равным 1.0343.

### 📝 Вывод

Все четыре метода показали одинаковые коэффициенты парной регрессии при отсутствии дублирующих признаков.

При добавлении копии G2 возникла линейная зависимость между столбцами, из-за которой матрица XᵀX стала вырожденной.

Методы `np.linalg.lstsq` и `LinearRegression` оказались устойчивее к этой ситуации, поскольку позволяют получить решение задачи наименьших квадратов без непосредственного обращения вырожденной матрицы.


## 3.5. П3. Признаки под линейную модель

Для исследования нелинейной зависимости выбран числовой признак `absences` — количество пропущенных занятий.
Построен график зависимости итоговой оценки `G3` от количества пропусков с отображением средних значений по интервалам.
Для преобразования признака применён `KBinsDiscretizer` со стратегиями `uniform` и `quantile`.
Проверены значения `n_bins = 4, 8, 12, 20`.

### 📊 Результаты экспериментов
| n_bins | uniform CV R² | quantile CV R² |
|---|---:|---:|
| 4 | 0.8212 | 0.8242 |
| 8 | 0.8195 | 0.8219 |
| 12 | 0.8191 | 0.824522 |
| 20 | 0.8206 | **0.824525** |
| Без бинаризации | 0.8216 | 0.8216 |

### 📈 Графики

В ходе исследования построены:

1. График зависимости G3 от absences с усреднением по интервалам.
2. График зависимости CV R² от числа интервалов для стратегий uniform и quantile.

### 📝 Вывод

Наилучший результат получен при использовании стратегии `quantile` с 20 интервалами: CV R² = 0.824525.

По сравнению с базовой моделью (CV R² = 0.821636) качество увеличилось на 0.002889.


Стратегия `uniform` не показала улучшения относительно базовой модели.

Увеличение количества интервалов не гарантирует повышения качества: при большом числе интервалов уменьшается количество наблюдений в отдельных группах, что может приводить к переобучению.

Кроме того, из-за повторяющихся значений absences фактическое число интервалов при стратегии quantile может быть меньше заданного.
Эксперимент показал небольшое улучшение качества, но увеличение количества интервалов не гарантирует дальнейшего роста CV R².

## 3.6. П4. Регуляризация и подбор α

Для улучшения прогнозирования итоговой оценки G3 исследованы методы регуляризации Ridge (L2) и Lasso (L1).

В качестве предобработки использован лучший вариант из П3: KBinsDiscretizer с 20 интервалами и стратегией quantile.

### Ridge: подбор коэффициента α

Проверены 40 значений α из диапазона от 10⁻⁴ до 10⁴ с использованием `np.logspace(-4, 4, 40)`.

Для каждого α рассчитаны Train RMSE и CV RMSE. Построен график зависимости ошибок от α в логарифмической шкале.

### 📊 Результаты Ridge

| Показатель | Значение |
|---|---:|
| Лучший α | 21.544347 |
| Train RMSE | 1.233051 |
| CV RMSE | 1.328212 |
| CV R² | 0.830479 |

### 📝 Вывод по Ridge

При слабой регуляризации наблюдается разрыв между ошибками обучения и кросс-валидации, что указывает на риск переобучения.

При чрезмерно сильной регуляризации ошибки увеличиваются, что свидетельствует о недообучении.

Наименьшая ошибка CV RMSE достигнута при α = 21.544347.

По сравнению с моделью из П3 CV R² увеличился с 0.824525 до 0.830479.

### Lasso: подбор коэффициента α

Для выбора параметра регуляризации использован LassoCV с 5-кратной кросс-валидацией.

Проведено сравнение двух способов кодирования категориальных признаков: OneHotEncoder(drop=None) и OneHotEncoder(drop="first").

### 📊 Результаты Lasso

| Показатель | drop=None | drop="first" |
|---|---:|---:|
| Лучший α | 0.051507 | 0.034864 |
| CV R² | 0.837774 | 0.837287 |
| CV RMSE | 1.299489 | 1.301371 |
| Всего коэффициентов | 65 | 48 |
| Обнулённых коэффициентов | 53 | 31 |

### Анализ обнулённых коэффициентов

При использовании Lasso с обычным OneHotEncoder обнулены 53 из 65 коэффициентов.

Среди обнулённых числовых признаков: age, Fedu, traveltime, goout и Walc.

Наиболее выраженное влияние на прогноз сохранил признак G2, отражающий оценку учащегося за второй учебный период.

При использовании OneHotEncoder(drop="first") число коэффициентов сократилось с 65 до 48, поскольку первая категория каждого категориального признака исключается и используется как базовая.

Количество нулевых коэффициентов уменьшилось до 31. Изменились также оптимальное значение α и распределение весов.

### 📝 Общий вывод

Регуляризация улучшила качество базовой линейной модели.

Ridge достиг CV R² = 0.830479  
Lasso показал CV R² = 0.837774  

Lasso обеспечил наилучшее качество среди рассмотренных вариантов и сократил число ненулевых коэффициентов до 12.

Использование OneHotEncoder(drop="first") изменило параметризацию модели и количество нулевых весов, но практически не повлияло на качество прогноза.

Результаты показывают, что регуляризация позволяет контролировать сложность модели, а Lasso дополнительно выполняет отбор признаков.


## 3.7. П5. Интерпретация модели

Для интерпретации выбрана модель Lasso с оптимальным
коэффициентом регуляризации α = 0.051507.

Важность признаков оценивалась двумя методами:
1. Анализ коэффициентов обученной модели.
2. Поочерёдное удаление исходных признаков и сравнение CV R².

### 📊 Коэффициенты Lasso

| Признак | Абсолютный коэффициент |
|---|---:|
| G2 | 2.451755 |
| G1 | 0.476178 |
| absences (интервал 0) | 0.220154 |
| school_GP | 0.079354 |
| failures | 0.047579 |
| Dalc | 0.045504 |

Наибольший коэффициент имеет признак `G2`, отражающий
успеваемость учащегося за второй учебный период.

Числовые признаки стандартизованы. Для категориальных
признаков и интервалов использовано one-hot кодирование.

### 📊 Важность признаков через удаление

Базовое качество Lasso: CV R² = 0.837774.

| Удалённый признак | Снижение CV R² |
|---|---:|
| G2 | 0.145489 |
| G1 | 0.005589 |
| absences | 0.002027 |
| studytime | 0.000149 |
| Mjob | 0.000138 |
| school | 0.000132 |

Наиболее значимым признаком оказался G2: его удаление
снижает CV R² на 0.145489.

### Анализ расхождения веса и важности

Признак G1 имеет сравнительно большой коэффициент
(0.476178), однако его удаление снижает CV R²
всего на 0.005589.

Причина — высокая корреляция G1 и G2:

**r(G1, G2) = 0.8561.**

Оба признака отражают академическую успеваемость.
Поэтому при удалении G1 модель продолжает получать
значительную часть аналогичной информации через G2.

Таким образом, величина коэффициента не всегда
соответствует вкладу признака в качество прогноза.

### Логарифмическое преобразование цели

Для итоговой оценки G3 рассчитана асимметрия
распределения:

**Асимметрия = -0.9913.**

Поскольку целевая переменная содержит нулевые значения,
для эксперимента использован TransformedTargetRegressor
с преобразованием log1p(G3).

### 📊 Сравнение моделей

| Модель | CV R² |
|---|---:|
| Обычная Lasso | 0.837774 |
| Lasso + log1p(G3) | 0.713375 |

Логарифмическое преобразование ухудшило качество
прогнозирования.

Для дальнейшего использования оставлена обычная Lasso.

### 📝 Вывод

Наибольшее влияние на прогноз итоговой оценки G3
оказывает предыдущая оценка G2.

Выявлено расхождение между величиной коэффициента G1
и его важностью через удаление, объясняемое высокой
корреляцией с G2.

Эксперимент с логарифмическим преобразованием цели
не улучшил качество модели.

Таким образом, лучшим решением остаётся Lasso
с CV R² = 0.837774.
