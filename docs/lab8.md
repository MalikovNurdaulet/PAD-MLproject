## 3.3. П1. Базовая модель LinearRegression

Для прогнозирования итоговой оценки учащихся `G3` построена базовая модель `LinearRegression`.

Предобработка данных и обучение объединены в `Pipeline`:

- Числовые признаки: `SimpleImputer(strategy="median")` и `StandardScaler`.
- Категориальные признаки: `SimpleImputer(strategy="most_frequent")` и `OneHotEncoder(handle_unknown="ignore")`.
- Модель: `LinearRegression`.
- Оценка качества: 5-кратная кросс-валидация.

Разница между CV R² и Test R² не указывает на выраженное переобучение, однако устойчивость модели необходимо дополнительно проверить.

## 3.4. П2. Формула метода наименьших квадратов (МНК)

Для парной линейной регрессии выбран признак `G2` — оценка учащегося за второй учебный период. Целевая переменная — итоговая оценка `G3`.

Коэффициенты регрессии рассчитаны четырьмя способами:

1. `np.linalg.inv()` — через обратную матрицу.
2. `np.linalg.solve()` — решение системы линейных уравнений.
3. `np.linalg.lstsq()` — метод наименьших квадратов.
4. `LinearRegression()` — реализация scikit-learn.

### 📊 Результаты расчёта коэффициентов

| Метод | w₀ | w₁ |
|---|---:|---:|
| np.linalg.inv | -0.0559 | 1.0343 |
| np.linalg.solve | -0.0559 | 1.0343 |
| np.linalg.lstsq | -0.0559 | 1.0343 |
| LinearRegression | -0.0559 | 1.0343 |

Полученное уравнение регрессии:

**G3 = -0.0559 + 1.0343 × G2**

При увеличении оценки G2 на один балл прогнозируемая итоговая оценка G3 увеличивается примерно на 1.03 балла.

### Проверка вырожденности матрицы

Для проверки добавлена копия признака G2.

### 📊 Результаты с дублирующим признаком

| Метод | Результат |
|---|---|
| np.linalg.inv | Singular matrix |
| np.linalg.solve | Singular matrix |
| np.linalg.lstsq | Успешное решение |
| LinearRegression | Успешное решение |

После дублирования признака матрица содержит три столбца, но её ранг равен двум.

Методы `inv` и `solve` не работают, поскольку матрица XᵀX вырождена и не имеет обратной матрицы.

Методы `lstsq` и `LinearRegression` находят решение, распределяя коэффициент исходного признака между двумя одинаковыми столбцами:

**w₁ = 0.5172, w₂ = 0.5172**

Суммарный коэффициент остаётся равным 1.0343.

### 📝 Вывод

Все четыре метода показали одинаковые коэффициенты парной регрессии при отсутствии дублирующих признаков.

При добавлении копии G2 возникла линейная зависимость между столбцами, из-за которой матрица XᵀX стала вырожденной.

Методы `np.linalg.lstsq` и `LinearRegression` оказались устойчивее к этой ситуации, поскольку позволяют получить решение задачи наименьших квадратов без непосредственного обращения вырожденной матрицы.


## 3.5. П3. Признаки под линейную модель

Для исследования нелинейной зависимости выбран числовой признак `absences` — количество пропущенных занятий.
Построен график зависимости итоговой оценки `G3` от количества пропусков с отображением средних значений по интервалам.
Для преобразования признака применён `KBinsDiscretizer` со стратегиями `uniform` и `quantile`.
Проверены значения `n_bins = 4, 8, 12, 20`.

### 📊 Результаты экспериментов
| n_bins | uniform CV R² | quantile CV R² |
|---|---:|---:|
| 4 | 0.8212 | 0.8242 |
| 8 | 0.8195 | 0.8219 |
| 12 | 0.8191 | 0.824522 |
| 20 | 0.8206 | **0.824525** |
| Без бинаризации | 0.8216 | 0.8216 |

### 📈 Графики

В ходе исследования построены:

1. График зависимости G3 от absences с усреднением по интервалам.
2. График зависимости CV R² от числа интервалов для стратегий uniform и quantile.

### 📝 Вывод

Наилучший результат получен при использовании стратегии `quantile` с 20 интервалами: CV R² = 0.824525.

По сравнению с базовой моделью (CV R² = 0.821636) качество увеличилось на 0.002889.


Стратегия `uniform` не показала улучшения относительно базовой модели.

Увеличение количества интервалов не гарантирует повышения качества: при большом числе интервалов уменьшается количество наблюдений в отдельных группах, что может приводить к переобучению.

Кроме того, из-за повторяющихся значений absences фактическое число интервалов при стратегии quantile может быть меньше заданного.
Эксперимент показал небольшое улучшение качества, но увеличение количества интервалов не гарантирует дальнейшего роста CV R².
