
## 📊 Этап 1. Разведочный анализ данных (EDA)

### 1.1. Описание датасета

Для исследования используется открытый набор данных **Student Performance** из UCI Machine Learning Repository, содержащий информацию об учащихся двух школ Португалии.

**Источник:** https://archive.ics.uci.edu/dataset/320/student+performance

| Характеристика | Значение |
|---|---|
| Файл | `student-por.csv` |
| Количество наблюдений | 649 |
| Количество столбцов | 33 |
| Числовые столбцы | 16 |
| Категориальные столбцы | 17 |
| Пропущенные значения | 0 |
| Полные дубликаты | 0 |
| Целевая переменная | `G3` |
| Диапазон G3 | 0–20 баллов |

**Цель анализа:** исследовать факторы, связанные с академической успеваемостью, и подготовить данные для прогнозирования итоговых оценок и риска неуспеваемости.

### 1.5. Анализ риска неуспеваемости

Для будущей задачи классификации определён бинарный показатель:

- `at_risk = 1`, если `G3 < 10`;
- `at_risk = 0`, если `G3 >= 10`.

| Категория | Количество | Доля |
|---|---:|---:|
| Группа риска (G3 < 10) | 100 | 15.41% |
| Успевающие (G3 >= 10) | 549 | 84.59% |
| **Всего** | **649** | **100%** |

**Вывод:** классы несбалансированы. Только 15.41% наблюдений относятся к группе риска.

Для ЛР9 необходимо учитывать дисбаланс при оценке классификаторов и использовать Precision, Recall, F1 и ROC-AUC, а не ограничиваться Accuracy.

### 1.11. Анализ потенциальных выбросов

Для поиска потенциальных выбросов использован метод межквартильного размаха (IQR).

Границы определены как:

- Нижняя: Q1 - 1.5 × IQR.
- Верхняя: Q3 + 1.5 × IQR.

| Признак | Нижняя граница | Верхняя граница | Выбросы | Доля |
|---|---:|---:|---:|---:|
| age | 13.0 | 21.0 | 1 | 0.15% |
| absences | -9.0 | 15.0 | 21 | 3.24% |
| G1 | 5.5 | 17.5 | 16 | 2.47% |
| G2 | 5.5 | 17.5 | 25 | 3.85% |
| G3 | 4.0 | 20.0 | 16 | 2.47% |

**Результаты:**

1. Один учащийся имеет возраст 22 года, превышающий верхнюю границу IQR.
2. У 21 учащегося количество пропусков превышает 15.
3. В оценках G1, G2 и G3 присутствуют потенциальные выбросы.
4. Для G3 выбросами по IQR являются значения 0 и 1 балл.
5. Выбросы не обязательно являются ошибками данных.

**Решение:** автоматически удалять такие наблюдения нецелесообразно. Низкие оценки, большое количество пропусков и возраст 22 года могут отражать реальные особенности учащихся.

Влияние потенциальных выбросов на качество моделей будет проверено на следующих этапах.

### 1.12. Итоговые выводы EDA

По результатам разведочного анализа установлено:

1. **Качество данных.** Датасет содержит 649 наблюдений и 33 столбца. Пропуски и полные дубликаты отсутствуют.

2. **Успеваемость.** Средняя итоговая оценка составляет 11.91 балла, медиана — 12 баллов.

3. **Академический риск.** 100 учащихся (15.41%) имеют итоговую оценку ниже 10 баллов.

4. **Предыдущие оценки.** G1 и G2 демонстрируют наиболее сильную положительную корреляцию с итоговой оценкой.

5. **Предыдущие неудачи.** Признак failures отрицательно связан с итоговой успеваемостью и представляет интерес для выявления академического риска.

6. **Время подготовки.** Более высокая категория самостоятельной подготовки в целом связана с лучшей успеваемостью.

7. **Категориальные характеристики.** Между группами учащихся наблюдаются различия в средних оценках и долях риска.

8. **Выбросы.** Обнаружены потенциально необычные значения возраста, пропусков занятий и оценок. На этапе EDA они сохранены.

9. **Ограничения.** Полученные связи не являются доказательством причинно-следственных эффектов. Данные относятся к двум школам Португалии, поэтому перенос результатов на другие образовательные системы требует дополнительной проверки.
